# MASTER — Wedding Template

## Purpose

Elegant, romantic wedding invitation page for a one-page event website.

## Tokens

| Role | Value |
|---|---|
| Ink | `#3e4a60` |
| Muted text | `#505d70` |
| Blue accent (`--sage`) | `#9196a6` |
| Dark blue accent (`--sage-dark`) | `#4f5c80` |
| Paper | `#f8f7f3` |
| White | `#ffffff` |

## Typography

- Script: Great Vibes
- Serif: Cormorant Infant
- Utility: Manrope

## Layout

- Hero: 100svh
- Invitation sections: full-width blue backgrounds
- Schedule width: 760px
- Mobile breakpoint: 700px
- Section padding: 96px desktop / 72px mobile

## Interaction

- Menu: slide-in navigation panel
- FAQ: native accordion
- RSVP: link to an external form
- Button motion: 150–300ms
- Respect `prefers-reduced-motion`
